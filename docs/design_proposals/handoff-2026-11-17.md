## 1. Current State Summary

We transformed `oauth-llm-nexus` from per-handler point-to-point mappers into a unified **4×7 Multi-Protocol API Aggregation Gateway** with a standalone Magpie-inspired console at **`GET /ui`** (preserving legacy OAuth `/`, `/auth/*`, `/genai/*`, and `/v1/publishers/google/*` workflows untouched).

### What Is Implemented & Verified

1. **Unified Gateway Engine (`internal/gateway/`)**:
   - **4 Frontend Protocols (`internal/gateway/codec*`)**:
     - OpenAI Chat Completions (`POST /v1/chat/completions`, `GET /v1/models`, `POST /v1beta/openai/chat/completions`)
     - OpenAI Responses API (`POST /v1/responses`)
     - Anthropic Messages API (`POST /anthropic/v1/messages`, `POST /v1/messages`, `GET /anthropic/v1/models`)
     - Google Gemini API (`GET /v1beta/models`, `GET /v1beta/models/{model}`, `POST /v1beta/models/{model}:generateContent|streamGenerateContent|countTokens|embedContent|batchEmbedContents`)
   - **7 Upstream Presets (`config/providers.yaml`, `internal/gateway/provider/presets.go`)**:
     - `openai`, `openrouter` (defaults to `free_only: true`), `nvidia` (`StreamFirst`), `amd`, `ollama` (`no_key: true`), `deepseek`, `gemini` (defaults to `key_strategy: round-robin`).
   - **Passthrough vs. IR Translation (`internal/gateway/server/attempt.go`, `passthrough.go`, `translate.go`)**:
     - Same-protocol targets use zero-copy passthrough (with `ApplyOpenAIChatQuirksJSON`, `StripReasoningSamplingJSON`, and `StreamFirst` collection when needed).
     - Cross-protocol targets parse into `ir.Request`, normalize reasoning effort (`internal/gateway/ir/effort.go`) and cached Gemini `thoughtSignature` (`internal/gateway/ir/sigstore.go`), stream upstream via SSE (`internal/gateway/sse/`), and encode downstream.
   - **Magpie P0 Resilience & Observability Enhancements**:
     - `ResponseStore` (`internal/gateway/ir/respstore.go`, 2048 cap / 2h TTL) bridging stateful `previous_response_id` across non-OpenAI translated backends.
     - Always-on `Metrics` (`internal/gateway/server/metrics.go`) + 128KB SSE rolling tail usage extraction (`>512KB` safe).
     - Header-aware rate limit parsing (`ParseRateLimitHeaders` in `router/classify.go`) honoring `Retry-After` / `x-ratelimit-reset-*` and proactive rotation on `x-ratelimit-remaining-requests: 0`.
     - Model capability filtering (`IsChatCapableModel`, toggleable via `include_non_chat`) & strict reasoning sampling guard (`o1`/`o3`/`o4`/`gpt-5*`).
   - **First-Class Gemini, Canonical Model Matrix & `GEMINI_API_KEYS` Relay**:
     - Gemini 3 & Gemini 4 (`gemini-4-hydrogen`, `gemini-4-argon`, `gemini-4-carbon`) `thinkingLevel` support in `codec/gemini/build.go`.
     - Client `?key=` sanitization (`sanitizeUpstreamQuery`) + multi-key retry for `:countTokens` / embeddings in `server.go`.
     - Canonical model normalization (`CanonicalModelID` in `provider/normalize.go`) feeding `router.go` fallback discovery, `GET /api/gateway/models/matrix`, and `POST /api/gateway/models/{client}/failover`.
     - Merged key env ingestion (`NEXUS_<ID>_API_KEYS`, `<ID>_API_KEYS` such as `GEMINI_API_KEYS`, `NEXUS_<ID>_API_KEY`, `<ID>_API_KEY`), `KeyStrategyRoundRobin` vs. `KeyStrategySticky` (`keys.go`), and `ClassifyGatewayError` rotating across keys on `503`/`529` and Google `400 API_KEY_INVALID` (`attempt.go`).
2. **Standalone Console UI (`internal/ui/`)**:
   - Zero-build Go `embed.FS` UI at `/ui` (`/ui/app.js`, `/ui/app.css`, `/ui/index.html`, `/ui/favicon.svg`):
     - **Providers & Catalog**: per-key health pills (`key_statuses`), `round-robin`/`sticky` strategy switch, live `enabled`/`free_only`/`include_non_chat` toggles, `prefer` selector, inline key add/remove, live telemetry strip, inline model `Test`.
     - **Routing & Model Matrix**: `Model Matrix` tab (`GET /api/gateway/models/matrix`), `Multi-Backend Only` filter, one-click `Sync Failover Group`, `Promote`/`Delete`/`Failover`/`Pinned`.
     - **4-Protocol Tester**: Co-equal OpenAI Chat, Responses, Anthropic, and Gemini cards across `Sync JSON`, `Stream SSE`, and `Tool Call` modes with full wire payload & `curl` copy.
     - **Connect & Logs**: SDK snippets (including `google.genai` Python SDK & `GOOGLE_GEMINI_BASE_URL`), API key reveal/copy, and expandable request logs.

## 4. Recommended Next Tasks (Backlog for Next Agent)

Ordered by value and readiness (see also `docs/design_proposals/magpie-practices-evaluation.md` P1/P2):

1. **[Done 2026-11-19] Persist Runtime Provider Config Changes**:
   - `PATCH /api/gateway/providers/{id}` now persists to `configs.gateway_provider_overrides` (`internal/gateway/server/overrides.go`) and `ApplyPersistedProviderOverrides` replays it in `main.go` before compat specs / catalog warmup. `DELETE /api/gateway/providers/{id}/overrides` resets. UI-added keys are plaintext in the local DB (same boundary as OAuth tokens); removed env keys are SHA-256 fingerprints. Open: at-rest encryption, `/ui` badge for `persisted_override`.
2. **Load-Distribution Routing Strategies (`round-robin`, `weighted`, `fastest`)**:
   - `Metrics` already tracks EWMA latency per provider (`EWMALatencyMS`). Extending `db.GetModelPolicy` & `router.Resolve` to support `round-robin` and `fastest` (sorting healthy non-cooled candidates by lowest `EWMALatencyMS`) unlocks smart load balancing across free/rate-limited pools (`openrouter`, `nvidia`, `amd`).
3. **Slow-Start SSE Keepalive Heartbeats & Pre-Commit TTFT Timeout**:
   - Emit periodic protocol-specific keepalives (`: keepalive\n\n` for OpenAI/Gemini, `event: ping\n\n` for Anthropic) when upstream cold starts (e.g. Ollama / reasoning models) exceed 10s before first chunk, paired with a separate pre-commit TTFT timeout for faster failover.
4. **Agent-Specific Onboarding Presets in `/ui` Connect**:
   - Add turnkey paste-ready presets for **Claude Code**, **Codex CLI**, **Gemini CLI / Antigravity**, and **Cursor** under `Connect & Logs`.
5. **Visual Browser Regression Checklist**:
